# Impacts of sampling coverage on bycatch estimates

Code for analyses found in:

> Correa, G.M., Ruiz, J., Ramos, M.L., Mugerza, A., Herrera, M., Alzorriz, N., Baez, J.C., 2026. How observation coverage shapes bycatch estimates in a tropical tuna purse seine fishery. Fisheries Research 298, 107754. [https://doi.org/10.1016/j.fishres.2026.107754](https://doi.org/10.1016/j.fishres.2026.107754)

Code found in the `code` folder. However, analyses are not reproducible since the data cannot be shared. Results from the simulation experiment can be found in the `model` folder. Figures can be found in the `figures` folder.
